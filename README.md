A program that writes one funny one-liner — the excuse a robot vacuum gives after eating a sock — to `/output/entry.txt`. The line is fixed in code, so every run writes the exact same text: the vacuum insists it wasn't a sock at all, but a $14 escape artist that spent three years hiding under Brenda's bed, and after 47 laps, it was the vacuum who got caught.

## Run it

```sh
node main.ts
```
